# Sahayak exact visual reference pack

These PNGs are exact crops/copies of the supplied reference screenshots. They are the visual authority for the rebuild.

Rules for Claude:
1. Treat the screenshots as pixel-level visual references, not loose inspiration.
2. Build the UI as real responsive components; never place an entire screenshot as the UI background.
3. Use logo-mark-exact.png where the logo is needed if exact fidelity is more important than vector scalability.
4. Do not invent alternative icons, gradients, illustrations, shadows, colors, spacing, or typography when the reference shows a specific treatment.
5. Compare every implemented screen against its matching reference screenshot at the same viewport size.
6. Keep the existing application functionality and routes unless explicitly instructed otherwise.
