# Sahayak Brand Usage

Primary: #102D63 (navy)
Accent: #F4A340 (saffron/orange)
Success: #2E9B67 (green)
Background: #F8FAFC
Text: #101828
Muted text: #667085

The Sahayak mark represents a person/community being supported by open hands.
The orange person element is the focal accent. Navy communicates trust and government-grade reliability.
Use the orange/white/green ribbon sparingly as a distinctly Indian identity cue.

Recommended use:
- Primary CTA: navy
- Verified/completed: green
- Deadline/warning: orange
- Neutral cards: white on #F8FAFC
- Avoid making every component colorful; color should communicate state.
